# 🚀 Git Starter

Learn how to properly set up Git and GitHub, including SSH keys, commit signing, and repository fundamentals.

## 🎯 What you will learn
- Configure Git identity (Author metadata vs Authentication)
- Generate and use SSH keys logically
- Sign your commits securely and understand verification
- Master the local commit loop (`init`, `add`, `commit`)
- Demystify `origin`, `upstream`, branches, and forks
- Troubleshoot common setup and connectivity errors

## 🛠️ Prerequisites
- Basic terminal usage
- A free GitHub account
